# แพลตฟอร์มเตรียมสอบตัวแทนประกันชีวิตไทย

## สถาปัตยกรรมหลัก

ลำดับการออกแบบของระบบคือ โครงสร้างข้อสอบ → แผนผังข้อสอบ → คลังข้อสอบ → เครื่องมือสุ่มข้อสอบ → วิเคราะห์ผล → ทบทวนข้อผิด → จัดเก็บข้อมูล → ส่วนติดต่อผู้ใช้ เพื่อให้ขยายไปสู่คลาวด์หรือ Supabase ได้โดยไม่ต้องรื้อโครงสร้างหลัก

## โครงสร้างโฟลเดอร์

- `types/` นิยามสคีมาข้อสอบ คำตอบ ประวัติสอบ ความก้าวหน้า และผลวิเคราะห์
- `data/` แผนผังข้อสอบ คลังข้อสอบ และบทเรียนทบทวน
- `services/` เครื่องมือสุ่มข้อสอบ วิเคราะห์ผล ทบทวนข้อผิด และเตรียมระบบจัดการข้อสอบ
- `hooks/` การเชื่อมสถานะผู้ใช้กับ Local Storage
- `features/` หน้าจอแดชบอร์ดและตัวทำข้อสอบ
- `components/` ส่วนประกอบ UI ที่ใช้ซ้ำ

## สคีมาข้อสอบ

ข้อสอบทุกข้อมี `id`, `category`, `topic`, `subtopic`, `difficulty`, `type`, `question`, `choices`, `correctAnswer`, `explanation`, `reference`, `tags`, `weight`, `estimatedTime` และ `sourceDocumentId` เพื่อรองรับการนำเข้า/ส่งออก JSON และการซิงก์คลาวด์ในอนาคต

## แผนผังข้อสอบ

ระบบใช้แผนผังข้อสอบ 60 ข้อ แบ่งเป็นจรรยาบรรณและศีลธรรม 20 ข้อ เกณฑ์ผ่าน 14 ข้อ และความรู้ประกันชีวิต 40 ข้อ เกณฑ์ผ่าน 24 ข้อ พร้อมสัดส่วนหัวข้อและระดับความยาก 30/40/20/10

## เครื่องมือสุ่มและปรับตัว

Mock Exam ใช้แผนผังข้อสอบคงที่และสุ่มข้อจากหัวข้อที่กำหนดโดยไม่ซ้ำ Practice/Weak/Wrong/Bookmark ใช้คลังเดียวกันและเลือกข้อจากสถิติผู้ใช้ ข้อที่ผิดจะเข้า Review Queue ตามกฎผิด 1 ครั้งทวนหลัง 10 หน่วย ผิด 2 ครั้งทวนหลัง 5 หน่วย ผิด 3 ครั้งทวนทันที

## การจัดเก็บข้อมูล

เวอร์ชันนี้จัดเก็บใน Local Storage ได้แก่ ประวัติสอบ สถิติหัวข้อ สถิติหมวด ระดับความยาก ข้อผิด บุ๊กมาร์ก ตราความสำเร็จ เวลาเรียน และคิวทบทวน โดยแยก service เพื่อเปลี่ยนเป็นฐานข้อมูลคลาวด์ได้ภายหลัง

## ระบบจัดการข้อสอบสำหรับผู้ดูแล

มี service สำหรับส่งออก JSON ตรวจสอบการนำเข้า ตรวจรหัสซ้ำ ตรวจจำนวนตัวเลือก และตรวจวัตถุประสงค์ซ้ำ เพื่อเตรียมต่อยอดหน้า `/admin/questions` สำหรับเพิ่ม แก้ไข ลบ นำเข้า ส่งออก และอัปโหลดจำนวนมาก

## หมายเหตุแหล่งอ้างอิง

โค้ดรองรับ `sourceDocumentId` สำหรับผูกข้อสอบกับเอกสารต้นฉบับ แต่ในพื้นที่ทำงานนี้ไม่พบไฟล์เอกสารสอบที่อัปโหลด จึงเตรียมโครงสร้างให้รับข้อมูลจากเอกสารต้นฉบับเมื่อมีไฟล์อยู่ในโปรเจกต์
